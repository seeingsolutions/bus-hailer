# Bus Hailer

A VoiceOver-friendly web app for showing bus numbers on a COOLLEDUX Bluetooth LED sign (the kind controlled by the CoolLED1248 app).

Open https://seeingsolutions.github.io/bus-hailer/ in the Bluefy browser on iPhone. Safari can't use Bluetooth.

Protocol details are based on the public reverse-engineering work in robot-pizza/led and zackmcmurrin-dev/coolledux-linux-uploader.
